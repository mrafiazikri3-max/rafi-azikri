Apa Itu Kabel LAN?

Local Area Network untuk menghubungkan perangkat dalam jaringan lokal.

Pengertian

Kabel LAN atau Local Area Network merupakan media transmisi yang digunakan untuk menghubungkan perangkat seperti komputer, laptop, switch, router, dan perangkat jaringan lainnya.


Pada praktik ini digunakan kabel UTP dan konektor RJ45. Kabel kemudian dirangkai sesuai standar susunan warna tertentu, dipasang pada RJ45 menggunakan tang crimping, kemudian diuji menggunakan LAN Tester.

Alat & Bahan

Peralatan yang digunakan dalam praktik.

🔌

Kabel UTP

Media penghantar data yang terdiri dari beberapa pasangan kabel tembaga yang dipilin.

🔗

RJ45

Konektor yang dipasang pada ujung kabel UTP agar dapat terhubung dengan port Ethernet.

🛠️

Tang Crimping

Digunakan untuk menekan pin konektor RJ45 agar terhubung dengan kabel UTP.

🧪

LAN Tester

Alat untuk memeriksa apakah susunan kabel LAN sudah tersambung dengan benar.

Cara Merangkai Kabel LAN

Langkah pembuatan kabel LAN menggunakan RJ45.

1

Potong Kabel UTP

Potong kabel UTP sesuai panjang yang dibutuhkan. Sisakan panjang yang cukup untuk proses pemasangan konektor RJ45.

2

Kupas Lapisan Kabel

Gunakan bagian stripper pada tang crimping atau alat pengupas kabel untuk membuka lapisan luar kabel UTP.

3

Atur Urutan Warna

Luruskan pasangan kabel kemudian susun sesuai standar T-568A atau T-568B.

4

Potong dan Ratakan

Setelah urutan warna benar, ratakan ujung kabel agar seluruh inti kabel dapat masuk ke dalam RJ45.

5

Masukkan ke RJ45

Masukkan semua kabel ke konektor RJ45 sampai ujung kabel menyentuh bagian depan konektor.

6

Crimping

Masukkan RJ45 ke tang crimping lalu tekan dengan kuat sampai pin konektor mengunci kabel.

7

Ulangi pada Ujung Lain

Pasang RJ45 pada ujung kabel lainnya sesuai jenis kabel yang ingin dibuat.

Pengujian dengan LAN Tester

Pastikan kabel yang dibuat dapat digunakan.

🔎 Cara Menggunakan LAN Tester

1

Masukkan RJ45 pada kedua ujung kabel ke port LAN Tester.

2

Nyalakan LAN Tester.

3

Perhatikan lampu indikator. Nomor pin harus menyala sesuai urutan yang benar.

4

Jika terdapat lampu yang tidak menyala atau urutannya salah, periksa kembali susunan kabel dan proses crimping.

Menghubungkan 2 Laptop

Menggunakan kabel LAN secara langsung.

💻

Laptop 1

IP: 192.168.1.1

🔗
💻

Laptop 2

IP: 192.168.1.2

Langkah Menghubungkan

1

Hubungkan kabel LAN ke port Ethernet Laptop 1 dan Laptop 2.

2

Buka pengaturan jaringan pada masing-masing laptop dan masuk ke pengaturan IPv4.

3

Laptop 1 dapat menggunakan IP 192.168.1.1 dengan subnet mask 255.255.255.0.

4

Laptop 2 dapat menggunakan IP 192.168.1.2 dengan subnet mask 255.255.255.0.

5

Uji koneksi menggunakan Command Prompt dengan perintah ping 192.168.1.2 dari Laptop 1.

Sharing File melalui LAN

Berbagi file dari Laptop 1 ke Laptop 2.

1

Pilih Folder

Pada Laptop 1, pilih folder yang ingin dibagikan.

2

Aktifkan File Sharing

Klik kanan folder → Properties → Sharing → Advanced Sharing → centang Share this folder.

3

Atur Permission

Atur izin akses sesuai kebutuhan, misalnya Read untuk membaca file atau Change untuk mengubah file.

4

Akses dari Laptop 2

Pada File Explorer Laptop 2, ketik alamat: \\192.168.1.1

5

Transfer File

Folder yang telah dibagikan akan muncul dan file dapat diakses sesuai permission yang diberikan.

Tips: Pastikan kedua laptop berada pada jaringan yang sama dan pengaturan Network Discovery serta File and Printer Sharing sudah aktif.

Kesimpulan

Pembuatan kabel LAN membutuhkan ketelitian dalam menyusun warna kabel UTP sesuai standar T-568A atau T-568B. Setelah konektor RJ45 dipasang menggunakan tang crimping, kabel perlu diuji menggunakan LAN Tester untuk memastikan setiap jalur terhubung dengan benar.


Kabel LAN juga dapat digunakan untuk menghubungkan dua laptop secara langsung. Setelah konfigurasi IP dilakukan, kedua laptop dapat saling berkomunikasi dan melakukan sharing file melalui jaringan lokal.
